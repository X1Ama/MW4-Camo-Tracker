- SAVE and RESTORE buttons: SAVE writes your progress to a file in Documents\MW4 Camo Tracker\Backups, RESTORE puts the last saved copy back
- RESET TAB now saves a safety copy first, so an accidental reset can be restored
- Admin panel: after setting a password you can see the user name and password (kept until the app is closed)
- New Android app: download MW4-Camo-Tracker.apk from the release page and open it on your phone
- RESET TAB button: clears the ticked camos in a tab and sets every weapon level back to 0 (asks first)
- The Linux and macOS versions now share their screens with the Android app
